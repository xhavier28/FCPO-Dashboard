----------------------------------------------------------------------
FINDING 1: DATA SOURCE TRACING
----------------------------------------------------------------------

The sweep panel (spread_behaviour_sweep.py) has TWO data sources:

SOURCE A -- daily_shape_log.csv / shape_log_enriched.csv (M1-M6):
  Generated by: research/01. regime_identification/Curve_Regime_Research.ipynb
  Incremental updates: dashboard/v1/shape_classifier.py update_shape_log()
  Raw data: individual per-contract CSVs in Raw Data/Term Structure/{year}/
    e.g. "FCPO Jun26_Daily.csv" -- one file per contract month
  Roll convention: front_month(date) -- day <=15 -> current month is M1,
    day >=16 -> next month is M1. This is the SAME day-16 roll rule used
    throughout the project (app.py, daily_term_combiner.py).
  Splicing method: RAW PRICE SPLICE. No ratio-adjustment, no back-
    adjustment. On day 16, Current jumps from the expiring contract
    settlement to the next month settlement. The absolute price level
    is discontinuous.
  Row-wise interpolation: app.py build_daily_table does linear interp
    on missing tenors, but the Curve_Regime_Research notebook does NOT.
    The original daily_shape_log.csv was built without interpolation.
  Coverage: 2008-01-01 to 2026-06-26 (4070 rows)

SOURCE B -- fcpo_daily_term_structure.xlsx (M7-M9, used for back-month
  and 2-month-gap instruments):
  Generated by: tools/daily_term_combiner.py
  Raw data: SAME individual per-contract CSVs
  Roll convention: SAME front_month(date) day-16 rule
  Splicing method: SAME raw price splice, no adjustment
  Coverage: 2020-01-02 to 2025-10-31 (1516 rows)

Both sources use identical construction logic (same load_contracts,
same front_month, same add_months). The xlsx is a materialized
snapshot of the same build_daily_table output.

M1-M6 values match exactly between the two sources (verified: only
1 mismatch on the last available date, 2026-03-10, likely a late
settlement update).

Roll dates are NOT recorded anywhere in the data or metadata. They
must be derived from the day-16 convention.

KEY IMPLICATION: All 20 instruments in the sweep use raw-price-spliced
rolling tenor positions. Spread values (M_near - M_far) experience a
discontinuity on every roll day because BOTH legs shift to different
underlying contracts simultaneously, and the price jump on the near
leg differs from the far leg.

in the butterfly formula (M_a - 2*M_b + M_c), producing a near-1.0x
ratio at day 16.

discontinuity because the SHAPE of the far curve changes when all
three legs shift forward by one contract month.

  M7: 1.20x, M8: 1.09x, M9: 1.14x
